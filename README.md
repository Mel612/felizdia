# Feliz Primer Día

Juego 2D de terror en bucle ambientado en **Unifranz, sede La Paz**. Valeria Quispe vive su primer día en la universidad una y otra vez, mientras un asesino disfrazado de Pepino la persigue. Para romper el bucle tiene que conocer las carreras, conseguir los 4 sellos del Pasaporte de Carreras y descubrir quién está detrás del disfraz.

Un juego de **Tres neuronas y un cromosoma**.

## Cómo abrirlo

1. Instala **Unity 6000.3.16f1** (Unity 6).
2. Clona el repositorio y ábrelo desde Unity Hub (**Add → Add project from disk**).
3. Abre la escena `Assets/FelizPrimerDia_Escena/Escenas/00_Menu` y dale **Play**.

## Controles

| Tecla | Acción |
|---|---|
| WASD / Flechas | Moverse |
| Shift | Correr |
| E | Hablar / usar |
| 1 – 4 | Elegir opciones |
| Espacio | Saltar (persecuciones) |
| Q | Mapa con las misiones |
| Tab | Cuaderno de pistas y logros |
| P | Pausa: guardar, opciones, volver al menú |
| M | Sonido |
| Esc | Saltar cinemáticas |

## Qué tiene

- 4 dificultades (Cachimbo, Universitario, Titulación, Pesadilla) y modo contrarreloj.
- 4 facultades jugables: Medicina, Derecho, Periodismo e Ingeniería de Sistemas, y 14 carreras para conocer.
- Misiones de indumentaria, persecuciones de lado, recuerdos en video y eventos al azar.
- Varios finales, logros y un personaje extra: **Mateo**.
- Un nivel escondido: el cuarto secreto.
- Guardado estilo Resident Evil: máquinas de escribir con 3 espacios.
- Pixel art, música y sonidos generados por código.

| Escena | Contenido |

Inspirado en *Feliz día de tu muerte*, *Resident Evil* y *Five Nights at Freddy's*.
